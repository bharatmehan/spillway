# Security Policy

## Supported versions

While this project is below 0.1, the most recent release is the only supported version.

| Version | Supported |
|---|---|
| Latest 0.0.x | Yes |
| Anything earlier | No |

## Reporting a vulnerability

Report privately through GitHub Security Advisories:

https://github.com/bharatmehan/spillway/security/advisories/new

Please do not open a public issue for a security problem, and please do not post details anywhere
public before a fix is available.

What to expect:

- An acknowledgement within seven days.
- An assessment, and a fix or an explanation of why it is not a vulnerability, within thirty days.
- Public disclosure within ninety days of the report, or as soon as a fix is released, whichever
  comes first.

If you would like credit in the advisory, say so in the report and name how you want to be
credited.
